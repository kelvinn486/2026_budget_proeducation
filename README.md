# 2026 예산 관리 (공용)

부서원이 함께 쓰는 예산 집행 관리 화면입니다. GitHub Pages로 배포됩니다.

| 사이트 | 주소(경로) | 화면 | 서버 코드 |
|------|------|------|------|
| 전문교육부 | `/` | `index.html` | `apps-script/Code.gs` |
| 포항혁신지구 지원사업 | `/pohang/` | `pohang/index.html` | `apps-script/pohang/Code.gs` |

- **데이터**: 사이트마다 별도의 Google 스프레드시트에 저장되며, 각 시트에 붙은 Google Apps Script 웹앱이 읽고 씁니다.
- **접근 제한**: 화면을 처음 열 때 부서 공용 비밀번호를 입력해야 데이터를 볼 수 있습니다.

## 폴더 구조

```
├── index.html              # 전문교육부 화면 (설정값 + 표 그리기만 담당)
├── pohang/index.html       # 포항혁신지구 화면 (설정값 + 그룹별 표 그리기만 담당)
├── assets/
│   ├── budget.css          # 두 화면 공용 스타일
│   └── budget-common.js    # 두 화면 공용 기능 (서버 통신, 입력·수정·삭제, 드래그, 백업)
└── apps-script/
    ├── Code.gs             # 전문교육부 서버 코드
    └── pohang/Code.gs      # 포항혁신지구 서버 코드
```

각 `index.html`의 `<script>` 맨 위에 그 화면만의 설정값이 모여 있습니다.

| 설정값 | 뜻 |
|------|------|
| `SCRIPT_URL` | 그 사이트의 Apps Script 웹앱 주소 |
| `PROGRAM_NAME` | 백업 파일에 적히는 사업 이름 |
| `BACKUP_PREFIX` | 백업 파일 이름 앞부분 |
| `USE_GROUPS` | `true`면 `groups` 시트를 읽어 항목을 그룹별로 묶어 보여 줌 |
| `DESC_PLACEHOLDER` | 집행 내용 입력칸의 예시 문구 |

## 스프레드시트 구조

모든 시트는 **첫 행이 제목 행**이고 둘째 행부터 데이터입니다.

### `items` (예산 항목)

| 열 | 전문교육부 | 포항혁신지구 |
|------|------|------|
| id | A열 고정. `item`으로 시작해야 함 (예: `item01`) | 제목이 `id`인 열 |
| name | B열 고정 | 제목이 `name`인 열 |
| budget | C열 고정 (숫자) | 제목이 `budget`인 열 |
| order | D열 고정 (화면 순서, 드래그하면 자동 갱신) | 제목이 `order`인 열 |
| group | — | 제목이 `group`인 열 (`groups` 시트의 id) |

- 전문교육부는 **열 위치**로 읽으므로 열 순서를 바꾸면 안 됩니다. id가 `합계`인 행은 무시됩니다.
- 포항은 **제목 이름**으로 읽으므로 열 순서는 자유입니다.

### `groups` (포항혁신지구만)

| id | name | order |
|------|------|------|
| 그룹 id | 화면에 보일 그룹 이름 | 그룹 표시 순서 |

`groups`에 없는 그룹을 가진 항목은 화면에서 **미분류**로 묶입니다.

### `executions` (집행 내역, 두 사이트 공통, 열 위치 고정)

| A | B | C | D | E | F |
|------|------|------|------|------|------|
| exec_id | item_id | date | desc | amount | author |

화면에서 입력하면 자동으로 행이 추가되므로 손으로 고칠 일은 거의 없습니다.

## 서버(Apps Script) 설정

### 전문교육부 (`apps-script/Code.gs`)
1. Apps Script 편집기에 코드를 붙여넣습니다.
2. `SHEET_ID`에 스프레드시트 ID(시트 주소의 `/d/`와 `/edit` 사이 문자열)를, `PASSCODE`에 부서 비밀번호를 넣습니다.
3. **배포 → 새 배포 → 웹 앱**(실행: 나, 액세스: 모든 사용자)으로 배포하고, 나온 주소를 `index.html`의 `SCRIPT_URL`에 넣습니다.

### 포항혁신지구 (`apps-script/pohang/Code.gs`)
1. 예산 시트에서 **확장 프로그램 → Apps Script**로 편집기를 엽니다. 이렇게 열면 시트와 자동 연결되므로 `SHEET_ID`는 **비워 둡니다**.
2. `PASSCODE`에 전문교육부와 같은 비밀번호를 넣습니다.
3. `setup` 함수를 한 번 실행해 권한을 승인합니다. 실행 로그에 그룹·항목·집행 내역 개수가 나오면 정상입니다.
4. 위와 같은 방법으로 웹 앱 배포 후, 주소를 `pohang/index.html`의 `SCRIPT_URL`에 넣습니다.

## 주의

`Code.gs`의 `SHEET_ID`와 `PASSCODE` 값은 자리표시자입니다.
실제 시트 ID와 비밀번호는 Apps Script 편집기에만 입력하고, 이 저장소에는 절대 올리지 마세요.

비밀번호는 각 부서원 브라우저에 저장되고, 웹앱 주소(`SCRIPT_URL`)는 공개 저장소에 그대로 보입니다.
즉 비밀번호 하나로만 보호되는 구조이니, 비밀번호가 새어 나갔다면 `PASSCODE`를 바꾸고 재배포하세요.

## 화면 수정 후 반영

화면 파일(`index.html`, `pohang/index.html`, `assets/`)을 고쳐 `main` 브랜치에 올리면 1~2분 뒤 모든 부서원 화면에 반영됩니다.

- `assets/` 안의 공용 파일을 고치면 **두 사이트 모두** 바뀝니다.
- 공용 파일을 고친 뒤에는 두 `index.html`에서 `?v=1` 숫자를 하나 올려 주세요(예: `?v=2`). 브라우저가 예전 파일을 계속 쓰는 것을 막아 줍니다.

Apps Script(`Code.gs`)를 고친 경우에만 편집기에 붙여넣고 **배포 관리 → 새 버전**으로 재배포합니다.
(새 배포를 만들면 주소가 바뀌니, 꼭 기존 배포의 **수정 → 버전: 새 버전**으로 올리세요.)

## 저장 방식 (빠른 반영)

입력·수정·삭제·순서 변경은 **화면에 먼저 반영**하고 서버 저장은 뒤에서 진행합니다.
저장 중인 줄은 흐리게 "저장 중…"으로 보이고, 저장이 실패하면 원래대로 되돌린 뒤 알림이 뜹니다.

서버는 저장에 성공하면 최신 목록을 함께 돌려줘서, 화면이 목록을 따로 다시 받지 않습니다.
예전 `Code.gs`가 배포된 상태여도 화면은 목록을 한 번 더 받아 오는 방식으로 정상 동작하므로, 화면과 서버 중 어느 쪽을 먼저 배포해도 괜찮습니다.

## 백업과 복구

화면의 **💾 백업** 버튼을 누르면 `사업명_예산_백업_날짜.json` 파일이 내려받아집니다.
여기에는 항목별 예산·집행·잔액과 전체 집행 내역(`executions`)이 들어 있습니다.

Google 시트에도 **파일 → 버전 기록**이 남으므로, 실수로 지운 내역은 보통 그쪽에서 되살리는 편이 빠릅니다.
JSON 백업은 시트 자체가 사라졌을 때 내역을 다시 옮겨 적는 용도로 보관하세요.
